# Calisthenics Log

A local-first workout log for **bodyweight training** — no gym equipment required.

## Features

- Log sessions with **date and time**
- Record sets as **reps** or **hold seconds**
- Built-in standard calisthenics (push-ups, squats, lunges, planks, burpees, and more)
- **Add and edit** exercise types
- Daily or weekly **goals** with progress from logged work

Data stays in your browser (`localStorage`). Clearing site data will erase the log.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
